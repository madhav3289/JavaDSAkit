# JavaDSAKit

A modular Java library implementing core data structures and algorithms.

## Modules
- Linked List
- Stack / Queue / Deque
- Binary Search Tree (BST)
- Trie
- Heap (Min/Max)
- Segment Tree
- Union Find
- Graph
- Cache (LRU / LFU)
- Algorithms (Sorting, DP)

## How to run
No Maven required. Compile and run with plain javac/java, or open in VS Code with the Java Extension Pack.
